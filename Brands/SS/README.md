# Brands/SS — production workspace

Production home for the **SS** brand.

- `Assets/` — SS evergreen assets (`Logos/`, `Icons/`, `References/`) reused across all SS sends.
- `Campaigns/Weekly/` and `Campaigns/Monthly/` — the six-stage pipeline
  (Brief → References → Assets → Draft → Review → Output) for each SS send.

**Brand facts & visual system** (identity, colours, typography, footer, product source) come from
`03-Brands/SS.md` and the approved `BrandConfig.md` / `Design.md` — injected at
generation time, **never hardcoded** in this workspace.
