# Brands/RDD — production workspace

Production home for the **RDD** brand.

- `Assets/` — RDD evergreen assets (`Logos/`, `Icons/`, `References/`) reused across all RDD sends.
- `Campaigns/Weekly/` and `Campaigns/Monthly/` — the six-stage pipeline
  (Brief → References → Assets → Draft → Review → Output) for each RDD send.

**Brand facts & visual system** (identity, colours, typography, footer, product source) come from
`03-Brands/RDD.md` and the approved `BrandConfig.md` / `Design.md` — injected at
generation time, **never hardcoded** in this workspace.
