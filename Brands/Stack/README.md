# Brands/Stack — production workspace

Production home for the **Stack** brand.

- `Assets/` — Stack evergreen assets (`Logos/`, `Icons/`, `References/`) reused across all Stack sends.
- `Campaigns/Weekly/` and `Campaigns/Monthly/` — the six-stage pipeline
  (Brief → References → Assets → Draft → Review → Output) for each Stack send.

**Brand facts & visual system** (identity, colours, typography, footer, product source) come from
`03-Brands/Stack.md` and the approved `BrandConfig.md` / `Design.md` — injected at
generation time, **never hardcoded** in this workspace.
