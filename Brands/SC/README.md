# Brands/SC — production workspace

Production home for the **SC** brand.

- `Assets/` — SC evergreen assets (`Logos/`, `Icons/`, `References/`) reused across all SC sends.
- `Campaigns/Weekly/` and `Campaigns/Monthly/` — the six-stage pipeline
  (Brief → References → Assets → Draft → Review → Output) for each SC send.

**Brand facts & visual system** (identity, colours, typography, footer, product source) come from
`03-Brands/SC.md` and the approved `BrandConfig.md` / `Design.md` — injected at
generation time, **never hardcoded** in this workspace.
